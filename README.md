
# 🏦 ATM Banking Management System

A modern and interactive ATM Banking Management System developed using HTML5, CSS3, and JavaScript.

This project simulates basic ATM operations through a professional banking dashboard with PIN validation, account verification, cash withdrawal, balance management, and transaction history.

## 🚀 Features

- Modern and responsive banking dashboard.
- Six-digit PIN validation.
- Accepts any six-digit PIN (demo simulation).
- No login attempt limit.
- Account Active / Inactive verification.
- Account Blocked / Unblocked verification.
- Cash withdrawal functionality.
- Real-time balance updates.
- Maximum withdrawal limit of $99,999.
- Insufficient balance validation.
- Transaction success and failure notifications.
- Live date and time display.
- Recent transaction history.
- Logout functionality.
- Mobile-friendly interface.

## 🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Application logic and interactivity.

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the project using Live Server.
5. Enter any six-digit PIN.
6. Verify your account status.
7. Start performing ATM transactions.

## 💡 Project Objectives

The main objective of this project is to understand how ATM systems work and implement basic banking operations using frontend web technologies.

It also demonstrates practical knowledge of:

- DOM Manipulation
- JavaScript Event Handling
- Conditional Statements
- Form Validation
- Functions
- Variables and State Management
- Responsive Web Design

## 🔮 Future Improvements

- Node.js and Express.js backend integration.
- MySQL database connectivity.
- Secure user authentication.
- Persistent transaction history.
- Multiple customer accounts.
- Deposit and fund transfer functionality.

## ⚠️ Disclaimer

This is an educational frontend simulation project.

It does not provide real banking services. PIN validation is intentionally simplified, and no real financial transactions are processed.
